Menu Icon
=========

Menu Icon enables you to add icon classes to menu links.


Requirements
------------

This module needs the core Menu module to be enabled.


Installation
------------

- Install this module using the official Backdrop CMS instructions at
  https://docs.backdropcms.org/documentation/extend-with-modules.

- There is no dedicated configuration page; configure icons on individual menu items when editing links.
